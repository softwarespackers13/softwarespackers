# Logo Files

## Main Company Logo

**Required file**: `swp-logo.png`
- This is the main SwP (Softwares Packers) logo with the red swoosh and TM mark
- Used in the website header and footer
- Recommended size: High resolution (at least 200px height)
- Format: PNG with transparent background (SVG preferred if available)

## Favicon

The logo is also used as the favicon. Make sure to:
1. Replace `/public/favicon.ico` with a square 32x32 or 64x64 pixel version
2. The logo should be recognizable at small sizes

## Client Logos

Place client company logos in this directory for testimonials and client showcase sections.

Example naming convention:
- `client-01.svg`
- `client-02.svg`
- `client-03.svg`

These files are referenced in the `clients.json` data file.
